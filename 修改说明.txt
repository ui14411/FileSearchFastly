perf:搜索改 SQL 分页+排序下推，修掉一次性取全表导致的卡顿

修复：
- 原来一次把符合条件的全部行取出来（旧 SQL 无 ORDER BY/LIMIT），再由前端过滤、线程池重排，
  数据量大时首屏慢、点排序要等 → 改为 500 条一页、SQL 里 ORDER BY/LIMIT，滚到底自动取下一页
- 点表头（名称/大小/修改时间）不能排序 → 支持点击排序，再点翻方向
- 换排序/切盘符要把已加载的行整体重排一遍 → 直接重查第 1 页，走索引（新增 idx_modifiedTime）
- 「返回上级」进的是文件系统的父目录 → 改为回到搜索结果页
 
提升：
- 后端拆成翻译/装配/执行三层，5 条搜索信号链收敛成 1 条（pagedResultReady → searchResultAll）
- 删死代码：前端排序链（requestSort/sortFile/applyModeFilter 等）+ 零引用的 3 个 enum，净删 236 行
